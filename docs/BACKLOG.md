## 5. 分かっている小さな問題 (未修正)

| 項目 | メモ |
|---|---|
| よく使う絵文字からカスタム絵文字を選ぶとクラッシュすることがある | 2026-10-02 の利用者のメモ。iOS シミュレータで再現せず (ピッカー単体・メッセージの「＋」のリアクション・ステータスの編集から、画像の読み込み中・GIF・画像が後から届く場合も。入力欄からは試せていない)。Android・Web は読んだ範囲で落ちる箇所なし。iOS build 61 で守りを固めた (「よく使う」は重複と無いカスタム絵文字を除く、カスタム絵文字の一覧で名前が重なっても落ちない)。また起きたら、どの画面から選んだか・端末の解析データ (設定 → プライバシー → 解析と改善 → 解析データの ChikuwaChat-…) を聞く |
| iOS: アクティビティからキャンバスを開くとき、同じ会話が隠れたタブのスタックにもあると「キャンバス」タブでなく「メッセージ」で開くことがある | `canvasOpen` を会話の id だけで照らし合わせているため (`pendingThread` と同じ)。M77 |
| チェックリストの行の印が消えることがある (スマホ) | iOS: 範囲の削除・単語の削除 (Option+Backspace)・ドラッグ。Android: 切り取って貼り直す、キーの連打。消えると行とタスクのつながりが切れるだけ (タスクは残る)。Android は編集欄を `TextFieldState` に移すのが本当の直し方 (CANVAS.md §22.9) |
| Android: オフラインでキャンバスの写しが出るまで時間がかかることがある | 写しはキャンバスの一覧の読み込みが失敗してから出す (CANVAS.md §19.2)。エミュレータでは通信の失敗に約 30 秒かかり、その間「読み込み中」。機内モードの実機ではすぐ失敗するはず。一覧の読み込み中から写しを出すなら設計の変更 (2026-10-03 の目視) |
| 締切の細かいところ | カレンダーの行に ⏰ が無い、通知の時刻は 9:00 で選べない、投稿に失敗した通知は再送しない (DEADLINES.md §9) |
| iOS のシミュレータ (Debug) で会話を横向きにすると固まる | 実機 (Release) では起きない。直す予定なし |
