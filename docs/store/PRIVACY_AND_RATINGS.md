# App のプライバシー / データ セーフティ / 年齢区分 の回答

前提: アプリは利用者が入力したサーバ (組織が運用) にだけデータを送る。開発者はデータを受け取らない。
ストアの定義では「端末の外に送ること」が「収集」なので、運用者のサーバに送るものも収集として答える
(`apps/ios/ChikuwaChat/Resources/PrivacyInfo.xcprivacy` (M103) と同じ内容にそろえる)。
根拠: docs/SECURITY.md、docs/PUSH_NOTIFICATIONS.md §5、docs/AI.md、docs/SSO.md、Info.plist、AndroidManifest.xml。

## 1. Apple: App のプライバシー (栄養ラベル)

- **トラッキング**: しない (ATT 不要。広告・解析 SDK なし。他社のデータと結び付けない)。
- **収集するデータ** (すべて「ユーザに関連付けられる」、目的は「App の機能」のみ、「トラッキングに使用」いいえ):

| 区分 | データの種類 | 中身 |
|---|---|---|
| 連絡先情報 | 名前 | 表示名 |
| 連絡先情報 | メールアドレス | 任意で設定するアドレス、Google ログインのアドレス |
| ユーザコンテンツ | メールまたはテキストメッセージ | チャットの本文 |
| ユーザコンテンツ | 写真またはビデオ | 添付、プロフィール画像 |
| ユーザコンテンツ | その他のユーザコンテンツ | ファイル、リアクション、投票、予定、タスク、キャンバス |
| 識別子 | ユーザ ID | サーバ上のユーザ ID / ユーザー名 |

- 収集しない: 位置情報、連絡先、健康、財務、閲覧履歴、検索履歴 (検索語はサーバに送るが保存しない。
  気になるなら「検索履歴」を追加してもよい)、購入、使用状況データ、診断 (クラッシュログを集めていない)、
  デバイス ID (広告 ID は使わない。プッシュのトークンは Apple の区分ではデバイス ID に当たらない)。
- 補足 (App Review への説明に使える): データの保存先は組織のサーバで、開発者のサーバではない。

## 2. Google Play: データ セーフティ

| 質問 | 回答 |
|---|---|
| 必須のユーザデータの種類を収集または共有しますか | はい |
| 収集したデータはすべて転送時に暗号化されますか | **いいえ** を推奨 (利用者が LAN の `http://` のサーバを指定できるため。本番のサーバは TLS)。運用で https に限るなら「はい」 |
| ユーザがデータの削除をリクエストする方法を提供していますか | はい (アプリ内の「アカウントを削除」と https://kano.ac/pages/apps/taylis-account-deletion/ ) |
| アカウントの作成 | 「ユーザ名とパスワード」+「その他 (組織の管理者が作成、組織の Google アカウント)」。アプリ内で新規作成はできない |
| 独立したセキュリティ審査 (MASA) | いいえ |
| 子ども向けのポリシー (ファミリー) | 対象外 (対象年齢 18 歳以上) |

収集するデータ (すべて「収集」、「共有」はなし。目的は「アプリの機能」と「アカウント管理」。「処理は一時的」いいえ。
任意か必須かは下の通り):

| カテゴリ | 種類 | 必須/任意 | 目的 |
|---|---|---|---|
| 個人情報 | 名前 | 必須 | アプリの機能、アカウント管理 |
| 個人情報 | メールアドレス | 任意 | アカウント管理 |
| 個人情報 | ユーザ ID | 必須 | アプリの機能、アカウント管理 |
| メッセージ | その他のアプリ内メッセージ | 必須 | アプリの機能 |
| 写真と動画 | 写真、動画 | 任意 | アプリの機能 |
| ファイルとドキュメント | ファイルとドキュメント | 任意 | アプリの機能 |
| アプリのアクティビティ | その他のユーザ作成コンテンツ (リアクション、投票、予定、タスク) | 任意 | アプリの機能 |
| デバイスまたはその他の ID | デバイスまたはその他の ID (FCM の登録トークン、Firebase のインストール ID) | 必須 | アプリの機能 (プッシュ通知) |

- 「共有」に当たらない理由: Google (FCM) への送信は「サービス プロバイダへの転送」、AI 事業者への送信は運用者が
  有効にしたときだけのサーバ側の処理で、どちらも Play の定義では共有の例外 (サービス プロバイダ / ユーザの操作による)。
  AI 機能を有効にしたサーバ向けに慎重に答えるなら「メッセージ」に「共有: はい (ユーザが開始した操作)」を足してもよい。
- 位置情報・連絡先・カレンダー (端末の)・健康・財務・閲覧履歴・音声・アプリの情報とパフォーマンス (クラッシュログ) は収集しない。
- 広告: 含まない。

## 3. 年齢区分

### Apple (App Store Connect の年齢区分の質問)

| 質問 | 回答 |
|---|---|
| 暴力・性的な内容・ヌード・冒とく・薬物・アルコール・ホラー・ギャンブル・医療情報などの各項目 | なし |
| ユーザ生成コンテンツ | はい (チャット) |
| メッセージとチャット | はい |
| 制限のない Web アクセス | いいえ (リンクは外部の Safari で開く。アプリ内ブラウザで任意の Web を見せない) |
| 広告 | いいえ |
| ペアレンタルコントロール / 年齢確認 | いいえ |
| コンテスト・懸賞 | いいえ |

結果の区分は App Store Connect が決める (メッセージとチャット + UGC で 13+ 程度の見込み)。

### Google Play (IARC の質問票)

- カテゴリ: 「ソーシャル、コミュニケーション…」系 (コミュニケーション / UGC)。
- ユーザ同士がやり取り・コンテンツを共有できる: はい。ユーザの位置情報の共有: いいえ。デジタル商品の購入: いいえ。
  制限のないインターネット: いいえ。暴力・性的・ギャンブルなど: いいえ。
- 対象年齢 (ターゲット ユーザー): 18 歳以上 (研究室・組織の利用。子ども向けではない)。
- ニュースアプリ: いいえ。政府のアプリ: いいえ。健康アプリ: いいえ。金融: いいえ。
