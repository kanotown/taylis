# MOBILE_POLISH (スマホを Slack のように洗練させるための差分リスト)

2026-09-30 の監査。iOS と Android のアプリを実際に動かして画面を撮り、Slack のモバイル版 (2025〜2026 年の版) と比べた。
設計の全体は [MOBILE_UI.md](MOBILE_UI.md)、順番は [ROADMAP.md](ROADMAP.md) §4 (MUI-1〜8) にある。
この文書は MUI-8 (仕上げ) と MUI-5 (入力欄) の中身を、画面で見えた差から具体的に決めるためのもの。

## 0. 条件と読み方

- **撮った環境**
  - iOS: iPhone 16e シミュレータ (iOS 26.2)、main の 7c59a49 をビルド
  - Android: Pixel 9 エミュレータ (API 36)、同じコミット
  - サーバ: 開発サーバ (127.0.0.1:8000)、android1 でログイン
  - テスト用の投稿は #audit-test に作った (リアクション、3 件の返信、写真 2 枚、リンク、PDF、メンション、箇条書き)
- **スクショ**: `ios/…png` と `android/…png` は、監査したセッションの scratchpad の `audit/` にある (リポジトリには入れていない)
  - 名前は `light-` / `dark-` + 番号 + 画面。例: `ios/light-10-channel.png`
- **確度**: Slack の挙動は記憶に基づく。自信があるものは書かず、自信がないものだけ「(確度 中)」「(確度 低)」と書いた
- **工数**: S = 半日以内、M = 1〜3 日、L = それ以上
- **対象外**: MUI-6 (DM 一覧のプレビュー、実装中)、ハドル・通話・ワークフロー・AI

### すでに Slack に近いところ (直さなくてよい)

- 下部タブ (ホーム / DM / アクティビティ / 自分)、ホームの横スクロールのタイル、右下の新規作成ボタン
- 長押しの操作シート (上にクイックリアクション 6 個 + ラベル付きの操作)。3 端末で内容と順番が揃っている
- 移動・検索 (最近の会話、最近の検索)、検索結果の絞り込みチップ
- アクティビティ (すべて / メンション / スレッド / リアクション、未読の点)
- 自分タブ (ステータス、通知の一時停止、おやすみ時間が上)
- ダークモードは両端末とも大きな崩れなし
