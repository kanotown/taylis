# 使い方

Taylis を使うメンバー向けの説明です。画面はデスクトップ版とブラウザ版のものですが、スマートフォンのアプリでも
同じことができます（違うところはそれぞれのページに書いています）。

## 画面の見かた

<div class="screens" markdown>
![デスクトップ版の画面。左がサイドバー、真ん中が会話と入力欄、右がスレッド（デモのデータ）](../assets/screens/web-overview.webp){ .full }
</div>

- **左（サイドバー）**：上に「スレッド」「アクティビティ」「ドキュメント」「カレンダー」「タスク」などの項目、その下に
  チャンネル・Times・DM の一覧。太字は未読、赤い数字は自分あてのメンションです。
- **真ん中**：開いている会話と、メッセージの入力欄。チャンネルの見出しのタブで「キャンバス」「予定」「タスク」に
  切り替えられます。
- **右**：スレッドやメンバーの一覧が開きます。
- **いちばん上**：戻る / 進むのボタンと、検索欄。
- **スマートフォン**：下に「ホーム」「DM」「アクティビティ」「自分」の 4 つのタブ。サイドバーの項目は、ホームのタイルに並びます。

## よく使う操作

| やりたいこと | 操作 |
| --- | --- |
| スレッドで返信する | メッセージにポインタを合わせて（スマートフォンは長押しして）「スレッドで返信」 |
| リアクションする | メッセージの 😊＋（リアクションを追加）、スマートフォンは長押し |
| メッセージを直す・消す | 自分のメッセージの ⋯（スマートフォンは長押し）から「編集」「削除」 |
| あとで読む | メッセージの 🔖（あとで見る）、または ⋯ →「リマインド…」 |
| チャンネルを探して参加する | サイドバーの「チャンネルを探す」 |
| 移動・検索 | 上の検索欄。会話やページへの移動は ++ctrl+k++（macOS は ++cmd+k++） |
| アンケートや日程調整を作る | 入力欄の ＋ →「アンケート」「日程調整」 |
| ステータスを出す | 左上の自分の名前 →「ステータスを設定」 |

困ったときは [FAQ](../faq.md) もご覧ください。
