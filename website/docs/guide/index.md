## 画面の見かた

<div class="screens" markdown>
![デスクトップ版 (デモのデータ)](../assets/screens/desktop.png){ .wide }
</div>

- **デスクトップ版・ブラウザ版**: 左にチャンネルと DM の一覧 (サイドバー)、真ん中に会話と入力欄、右にスレッドが
  開きます。いちばん左の細い列は、登録したワークスペースの切り替えです。
- **スマートフォン**: 下に「ホーム」「DM」「アクティビティ」「自分」の 4 つのタブがあります。設定は「自分」の中です。
- **タブレット (iPad・Android)**: デスクトップ版のように、一覧・会話・スレッドが横に並びます。

## よく使う操作

| やりたいこと | 操作 |
| --- | --- |
| スレッドで返信する | メッセージにポインタを合わせて (スマートフォンは長押しして)「スレッドで返信」 |
| リアクションする | メッセージの「リアクション」ボタン、またはスマートフォンでは長押し |
| メッセージを直す・消す | 自分のメッセージの ⋯ (長押し) から「編集」「削除」 |
| あとで読む | ⋯ から「保存」または「リマインダー」 |
| チャンネルを探して参加する | サイドバーの「チャンネルを追加」 |
| 移動・検索 | 上の検索欄。デスクトップ版は ++ctrl+k++ (macOS は ++cmd+k++) |
| 投票を作る | 入力欄の ＋ から投票、または `/poll 質問 \| 選択肢 \| 選択肢` |
| テンプレートを入れる | 入力欄の「テンプレート」、または `/日報` のように `/名前` |

困ったときは [FAQ](../faq.md) もご覧ください。
