# サイドバーと表示

## セクション

サイドバーのチャンネルや DM は、自分で作ったセクションにまとめられます (例:「授業」「研究」「プロジェクト」)。

- **作る**: サイドバーのメニューか、会話の右クリックのメニューの「新しいセクション…」で作ります。
- **会話を入れる**: 会話をセクションの見出しにドラッグするか、会話を右クリックして「セクションに移動」
  (デスクトップ版・ブラウザ版)。
- **並べ替える**: セクションの見出しをドラッグします。キーボードでは見出しの ⋯ の「上へ」「下へ」。
- **アイコン**: セクションには絵文字か **文字のアイコン** (英数字 1〜2 文字か日本語 1 文字に、8 色の背景) を付けられます。
  たとえば「修論指導」に「M」、「卒論指導」に「B」。
- 既定のセクション (お気に入り・チャンネル・Times・DM) は動かせません。

セクションはアカウントに保存されるので、ほかの端末でも同じになります。

## サイドバーの項目 (ホームのタイル)

サイドバーの上の項目 (スレッド・アクティビティ・下書き・リマインダー・ファイル・キャンバス・カレンダー・タスク・締切・
予約・保存済み) は、使わないものを隠したり、並べ替えたりできます。

- デスクトップ版・ブラウザ版: 設定 →「表示」→「サイドバーの項目」(スイッチ、ドラッグか ↑ / ↓、「元に戻す」)
- iPhone / iPad: 自分 →「表示」→「ホームのタイル」
- Android: 自分 →「表示」→「ホームのタイル」

並びと表示はアカウントに保存され、パソコンのサイドバーとスマートフォンのホームのタイルで同じになります。
「下書き」と「リマインダー」は、中身があるときだけ表示されます。

## テーマと色 (デスクトップ版・ブラウザ版)

設定 →「表示」で、次を端末ごとに選べます。

| 項目 | 選べるもの |
| --- | --- |
| ライト / ダーク | ライト・ダーク・端末に合わせる |
| テーマの色 | Taylis (栗、既定)・藍・緑・紫・紅・グレー |
| サイドバー | 濃い色・明るい色 (明るい色はライト表示のときだけ) |
| フォント | Noto Sans JP (既定、アプリに同梱)・システムのフォント |
| 文字の大きさ | 80〜200% (デスクトップ版だけ) |

文字の大きさは、キーボードでも変えられます: ++ctrl+plus++ で大きく、++ctrl+minus++ で小さく、++ctrl+0++ で 100%
(macOS は ++cmd++)。ブラウザ版は、ブラウザの拡大の機能を使ってください。

スマートフォンは、端末のライト / ダークと文字の大きさの設定に従います。

## ステータス

設定の一覧の上の「ステータスを更新」で、絵文字と一言 (例: 🏠 在宅、📚 授業中) と、表示する期間を決められます。
