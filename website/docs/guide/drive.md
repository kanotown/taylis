# ドライブ

「ドライブ」は、研究室のファイルをフォルダに分けて置いておく場所です（Nextcloud や Google ドライブに近いものです）。
会話の添付と違って流れていかず、論文の PDF・発表資料・実験のデータなど、大きなファイルも置けます（既定は 1 ファイル 5 GB まで）。

デスクトップ版とブラウザ版ですべての操作ができます。スマートフォンのアプリ（iPhone・iPad・Android）では、見る・探す・ダウンロードする・
アップロードするができます（[スマートフォンで使う](#phones)）。

## 3 つの場所

アイコン列の「ドライブ」（ハードディスクのアイコン）を開くと、左に場所が並びます。

| 場所 | 見られる人 |
| --- | --- |
| **研究室ドライブ** | ゲスト以外の全員 |
| **チャンネルのドライブ** | そのチャンネルのメンバー（公開・非公開チャンネル。DM にはありません） |
| **マイドライブ** | 自分だけ（管理者も中は見られません） |

「教員だけ」「M2 だけ」のように一部の人で使うファイルは、その人たちの非公開チャンネルのドライブに置きます。
まだドライブを開いていないチャンネルは「＋ チャンネルを選ぶ」から開けます。チャンネルの見出しの「ドライブ」のタブからも、
そのチャンネルのドライブを開けます。

場所の名前の下には、使っている容量が出ます（管理者が上限を決めていれば、その割合の棒も）。

チャンネルに投稿したファイルは、そのチャンネルのドライブの「投稿のファイル」にも入ります（[下](#channel-files)）。
行事の写真は [アルバム](albums.md) にまとめられます（ドライブの場所の一覧のいちばん上の「アルバム」）。

## アップロードする

- ファイルやフォルダを、一覧にドラッグ＆ドロップします。フォルダの行の上に落とすと、そのフォルダの中に入ります。
- または「アップロード」→「ファイルをアップロード」「フォルダをアップロード」で選びます。フォルダは中のフォルダの形のまま入ります
  （空のフォルダも）。

右下にアップロードの欄が出て、ファイルごとの進み具合・速さ・残り時間が見られます。欄は別の画面に移っても残ります。

- **一時停止・再開・取りやめ** は、行のボタン（全部まとめてなら見出しのボタン）で。
- **ネットワークが切れても**、つながれば続きから送ります（「接続を待っています」と出ます）。最初からやり直すことはありません。
- **アプリを閉じても**、デスクトップ版は次に開いたときに続きから送ります。ブラウザ版はタブを閉じるとファイルを読み直せないため、
  「途中のアップロードが n 件あります」と出たら「ファイルを選び直す」で同じファイルを選んでください。続きから送ります
  （途中までの分はサーバに 24 時間残ります）。

### 同じ名前のファイルがあるとき

アップロードするフォルダに同じ名前のファイルがあると、どうするかを聞かれます。

- **上書きして新しいバージョンにする**：新しいものに置き換えます。前のものは古いバージョンとして残ります。
- **名前を変えて両方残す**：「名前 (1).pdf」のように名前を変えて置きます。
- **スキップ**：そのファイルは送りません。

「残りすべてに同じ操作」に印を付けると、その回のアップロードの残りにも同じ答えを使います。

## 見る・探す・ダウンロードする

- **リストとグリッド**：右上で切り替えます（この端末で覚えます）。リストは見出しを押すと名前・更新日時・大きさで並べ替えます。
- **開く**：フォルダもファイルも 1 回のクリックで開きます。フォルダは中へ、写真・動画・PDF・Word / Excel / PowerPoint は
  アプリの中のビューアで見られます（写真と動画は ← → で同じフォルダの前後へ）。そのほかのファイルは右に詳細が出ます。
  ダウンロードされるのは「ダウンロード」を押した時だけです。
- **プレビューを作成中**：Nextcloud から移したばかりの Word / Excel / PowerPoint は、初めて開いた時にプレビューを作ります。
  「プレビューを作成中…」と出ている間そのまま待つと、できたところで中身が出ます。PDF は待たずにすぐ開きます。
- **選ぶ**：行の左のチェックボックス、または ++ctrl++ / ++shift++ を押しながらクリック（macOS は ++cmd++）。選んでいる間は
  上に「n 件を選択中」と、ダウンロード・共有リンク・コピー・移動・ゴミ箱へのボタンが出ます。++esc++ で選ぶのをやめます。
- **場所の一覧をたたむ**：フォルダの名前の左のボタンで、左の場所の一覧をたためます。一覧が広くなり、同じボタンでまた出せます。
  たたんだままでも、いちばん左の場所の名前の横の ▾ からほかの場所へ移れます。
- **行のボタン**：マウスを乗せた行の右に「共有リンク」と「ダウンロード」、⋯ にそのほかの操作があります。ゴミ箱と並べ替えは右上の ⋯ から。
- **戻る・進む**：上の ← →（++cmd+bracket-left++ / ++cmd+bracket-right++、Windows は ++alt+left++ / ++alt+right++、マウスの戻る /
  進むボタン、ブラウザの戻る / 進む）で、前に開いていたフォルダや場所に戻れます。
- **探す**：上の検索欄で、その場所の中をファイル名・フォルダ名と **ファイルの中身** で探します。全部の場所から探すときは、
  いちばん上の検索欄で探して結果の「ドライブ」のタブを開きます。中身の探し方は下の「[ファイルの中身を探す](#search-inside)」。
- **ダウンロード**：右クリック（または行の ⋯）→「ダウンロード」。デスクトップ版は「ダウンロード」フォルダに保存し、大きなファイルも
  少しずつ書き込みます。ブラウザ版はブラウザ自身のダウンロードになり、途中で切れてもブラウザの「再開」が使えます。
- **ZIP でダウンロード**：フォルダ、または複数選んだファイルとフォルダは、右クリック →「ZIP でダウンロード」で 1 つの ZIP に
  まとめて落とせます（詳細の欄の「ZIP でダウンロード」は、選んだもの、何も選んでいなければ開いているフォルダ全体）。
  フォルダの形・日本語の名前・空のフォルダもそのまま入り、Windows のエクスプローラーと macOS で展開できます。圧縮はしないので、
  大きさは元のファイルの合計とほぼ同じです。1 つの ZIP は 10,000 件・20 GB まで。それより大きいときはフォルダを分けて落としてください。
  ZIP は途中から再開できないので、とても大きなフォルダは分けるのがおすすめです。
- **詳細**：右上の ⓘ で、大きさ・種類・作った人・更新した人・バージョンの数・場所が見られます。

### ファイルの中身を探す { #search-inside }

検索欄の語は、ファイル名だけでなく **ファイルの中の文字** からも探します。日本語・英語のどちらも、語の一部でも見つかります。

- **探せるファイル**：PDF、Word / Excel / PowerPoint（プレビューと同じ PDF にしてから）、テキスト・Markdown・CSV（Excel が書く
  Shift_JIS の CSV も）。写真・動画・ZIP などの中は探しません。
- **結果の見え方**：名前が合ったものが先に出ます。中身で見つかったファイルには、名前の下に「**中身 · 3 ページ目**」と、見つかった語の
  前後の文が出て、語に色が付きます。
- **そのページを開く**：中身で見つかった PDF・Word などを開くと、ビューアはその語のあるページから始まります。
- **探せないもの**：スキャンした PDF（文字ではなく画像のもの。文字の読み取り（OCR）はまだしません）と、パスワードの付いた PDF。
  1 つのファイルで探すのは最初の約 1 MB の文字までです（数百ページ分）。
- **新しいファイル**：アップロードしてから、ふつうは数十秒で中身も探せるようになります（Word などはプレビューができてから）。
  新しいバージョンを上げると、前のバージョンの中身では見つからなくなり、新しい中身で探せます。ゴミ箱のファイルは出ません。
- **見る権限**：自分が見られる場所（研究室ドライブ、自分のマイドライブ、自分がメンバーのチャンネルのドライブ）のファイルだけが出ます。
- スマートフォンのアプリでも、検索の結果に見つかった語の前後が出ます。

## 整理する

- **新しいフォルダ**：上の「新しいフォルダ」。
- **名前を変更・移動・ゴミ箱へ**：右クリック（または ⋯）から。移動は行を別のフォルダやパンくずにドラッグしても、++ctrl+x++ →
  移動先で ++ctrl+v++（macOS は ++cmd++）でもできます。別の場所（研究室ドライブからチャンネルのドライブなど）へも移せます。
- **コピー**：右クリック →「コピー」で、コピー先のフォルダを選びます（書ける場所ならどこでも。同じフォルダにも）。または
  ++ctrl+c++ → コピー先で ++ctrl+v++（macOS は ++cmd++）。同じ名前があれば「名前 (1).pdf」のようになります。フォルダは中身ごと
  コピーされます（ゴミ箱のものは除く）。ファイルは現在のバージョンだけがコピーされ、コピーは新しいファイルとしてバージョン 1 から始まります。
  1 回にコピーできるのは 500 件・1 GB までです。コピーした分も、コピー先の容量に数えます。
- **キー**：++up++ ++down++ で選ぶ、++enter++ で開く（ほかのファイルは詳細）、++space++ でプレビュー、++f2++ で名前を変更、++delete++ でゴミ箱へ、
  ++ctrl+a++（macOS は ++cmd+a++）ですべて選ぶ、++ctrl+c++ / ++ctrl+x++ → ++ctrl+v++ でコピー / 移動。

### バージョン履歴

同じ名前で上書きする（アップロードで「上書きして新しいバージョンにする」を選ぶ）と、前のものは **古いバージョン** として残ります。
ファイルを右クリック →「バージョン履歴」（または詳細の欄の「バージョン」）で、バージョン一覧が見られます。

- どのバージョンも ⬇ でダウンロードできます。
- **このバージョンに戻す**：そのバージョンの写しが、新しい「現在のバージョン」になります。間のバージョンも消えないので、戻したあとでまた別のバージョンに戻せます。
  書ける人なら誰でもできます。
- **削除**（ごみ箱のアイコン）：古いバージョンを完全に削除します。完全に削除できる人（研究室ドライブは管理者、チャンネルのドライブは
  チャンネルのオーナー、マイドライブは本人）だけです。現在のバージョンは削除できません。
- 古いバージョンは、新しいものから **10 個まで**、新しいバージョンに置き換えられてから **30 日間** 残り、それを過ぎると自動で消えます
  （サーバの設定で変えられます。一覧の上に今の決まりが出ます）。
- 古いバージョンも、その場所の容量に数えます。プレビューは現在のバージョンだけです（古いバージョンはダウンロードして開きます）。

### 容量

場所の名前の下に、使っている容量が出ます。管理者が上限を決めていれば、その割合の棒も出ます。上限を超えると、
アップロード・コピー・古いバージョンに戻す・別の場所からの移動ができなくなります（「ドライブの容量の上限を超えます」）。
ゴミ箱のものを「完全に削除」するか、古いバージョンを削除すると空きます。使っている容量には古いバージョンとゴミ箱の分も入ります。

### ゴミ箱

右上の ⋯ →「ゴミ箱を開く」で、その場所のゴミ箱が開きます。ゴミ箱のものは 30 日たつと完全に削除され、それまではいつでも
「元に戻す」で元の場所に戻せます（元のフォルダが無ければいちばん上に）。「完全に削除」は、研究室ドライブは管理者、
チャンネルのドライブはチャンネルのオーナー、マイドライブは本人だけができます。

## 学外の人に渡す（共有リンク） { #share }

ファイルやフォルダを、Taylis にアカウントの無い人（他大学の共同研究者など）に **リンク** で渡せます。リンクを知っている人は
誰でも、ログインせずにブラウザで開けます。

1. ファイルかフォルダを右クリック（または行の ⋯）→「**共有リンク**」。
2. 「新しいリンク」で決めて「**リンクを作る**」。
    - **期限**：1 日・7 日（既定）・30 日・90 日、または日付を指定。いちばん長い期限は管理者が決めています（既定 90 日）。
    - **パスワード**（任意。管理者が必須にしていることもあります）：パスワードは、リンクとは別の方法（電話・別のメッセージなど）で伝えてください。
    - **ダウンロードの回数の上限**（任意）：ファイルのダウンロードと「ZIP でダウンロード」を 1 回ずつ数えます。一覧を見る・
      プレビューは数えません。
    - **誰向けか**（任意）：自分と管理者の一覧に出るメモです（相手には見えません）。
3. 出てきた URL を「**コピー**」して、相手に送ります。

!!! warning "URL は作ったときにだけ表示されます"
    サーバにはリンクの URL の写しを残しません（漏れても使われないように）。あとからもう一度表示することはできないので、
    渡し直すときは新しいリンクを作ってください（古いほうは「取り消す」）。

- **フォルダのリンク** は、そのフォルダの中のすべて（**あとから入れたものも**）が見えます。外部に共有されているフォルダの中を開くと、
  一覧の上に「このフォルダは外部共有リンクで公開されています」と出ます。共有したくないファイルは、そのフォルダに置かないでください。
- **ファイルのリンク** は、そのファイルの現在のバージョンだけが見えます（古いバージョンは見えません）。
- 相手のページ（`/s/…`）では、名前・大きさ・更新日時、ダウンロード、フォルダの「すべてを ZIP でダウンロード」、PDF・Word / Excel / PowerPoint の
  プレビュー、画像が見られます。**あなたの名前・研究室ドライブの中の場所・ほかのファイルは見えません。**
- 共有しているファイルとフォルダには、一覧の名前の横にリンクのしるしが付きます。

### リンクを管理する

「共有リンク」のダイアログの下に、その項目のリンクが並びます（自分が作ったもの。チャンネルのオーナーと管理者には全部）。
ドライブの左下の「**共有リンク**」には、自分が作ったすべてのリンクが並びます。

- **状態**：有効、期限切れ、回数の上限、停止中。
- **記録**：開いた・ダウンロードした・パスワードを間違えた日時（180 日残ります。IP アドレスは前の 2 つの区切りだけ）。
- **取り消す**：リンクはすぐに使えなくなります（元に戻せません）。

リンクは、次のあいだ **自動で止まります**（「停止中」。元に戻ればまた使えます）：

- 作った人がその場所を読めなくなった（チャンネルを抜けた・ゲストになった・アカウントが無効になった）
- そのチャンネルがアーカイブされた
- 項目をゴミ箱に入れた、または別の場所（ほかのチャンネルのドライブなど）へ移した
- 管理者がワークスペース全体で、またはその場所を管理する人がその場所で、外部リンクを止めた

リンクを作れるのは、その場所に書ける人だけです（ゲストは作れません）。ドライブのいちばん上（研究室ドライブ全体など）は共有できません。
チャンネルのオーナー（マイドライブは本人、研究室ドライブは管理者）は、場所の名前の ⋯ →「この場所で外部共有リンクを許す」で、
その場所のリンクを止められます。

## 会話と行き来する { #conversations }

### ドライブのファイルを会話に送る

入力欄の ＋ →「**ドライブから**」でファイルかフォルダを選び、送り方を選びます（ドライブの一覧で右クリック →「会話に送る」でも。
選んだ会話の入力欄にリンクが入ります）。

| 送り方 | 中身 | 見られる人 |
| --- | --- | --- |
| **リンクを入れる**（ふつうはこちら） | 本文にファイルのリンク（`…/d/…`）が入り、会話ではカード（名前・場所・大きさ）になります。押すとビューアかドライブで開きます | **そのドライブを見られる人だけ**。見られない人には「表示できないファイル」とだけ出ます（名前も出ません）。あとで名前を変えたり新しいバージョンにしたりしても、カードはドライブの今のファイルを指します |
| **コピーを添付** | その時点のバージョンを、ふつうの添付として送ります（100 MB まで。フォルダは送れません） | メッセージを読める人全員。あとでドライブのファイルを変えても、添付は変わりません |

会話の中に、そのファイルを見られない人がいると（ゲストのいるチャンネルに研究室ドライブのファイル、別のチャンネルのドライブのファイル、
マイドライブのファイルなど）、送る前に「このチャンネルの 3 人はこのファイルを見られません。」と出ます。そのときは「コピーを添付」
（入力欄の上の注意なら「**コピーとして送る**」）にすると、全員に届きます。そのまま送ってもかまいません（リンクを送っても、
見られる人は増えません）。

ファイルのリンクは、右クリック →「リンクをコピー」でも取れます。メッセージに貼ると同じカードになります。

### 会話の添付をドライブに保存する

メッセージの ⋯ →「**ドライブに保存**」（写真や PDF のビューアの上の行、チャンネルの「ファイル」の一覧の行からも）で、
添付をドライブのフォルダに保存できます。保存先は、そのチャンネルのドライブ（DM ならマイドライブ）から始まり、書き込める
ほかの場所とフォルダも選べます。同じ名前があれば「名前 (1).txt」のようにして置きます。

保存したものは **コピー** です。元のメッセージを消してもドライブのファイルは残り、ドライブで消してもメッセージの添付は変わりません。

## チャンネルに投稿したファイル（投稿のファイル） { #channel-files }

公開・非公開チャンネルのメッセージに付けたファイルは、送ったときに **そのチャンネルのドライブの「投稿のファイル」** の、
投稿した月のフォルダ（「投稿のファイル › 2026-10」）にも入ります。スレッドの返信も同じです。あとから「先月のゼミの資料」を
ドライブで探したり、名前や中身で検索したり、まとめて ZIP で落としたりできます。DM とグループ DM のファイルは入りません
（ドライブが無いため。メッセージの ⋯ →「ドライブに保存」で写せます）。

ファイルは 1 つだけで、メッセージの添付とドライブの項目を兼ねます（容量も 1 回分です）。入力欄には「ファイルは #… のドライブ
『投稿のファイル』にも保存されます」と出ます。

- **メッセージは投稿したときのファイルを指し続けます。** ドライブで同じ項目に新しいバージョンを上げても、メッセージの添付は
  変わりません。ビューアの上の行に「新しいバージョンがあります」と「最新を開く」が出ます。いつも今のファイルを指したいときは、
  ドライブのファイルの [リンク](#conversations) を送ります。
- **ドライブで整理しても壊れません。** 名前を変えても、同じチャンネルのドライブの中でフォルダを移しても、メッセージの表示は
  そのままです。メッセージの ⋯ →「**ドライブで表示**」、ビューアの上の行の「ドライブ：#… › 投稿のファイル › 2026-10」から、
  ドライブのその項目へ移れます。ドライブの詳細の「投稿」には、誰がいつどこに投稿したかと「メッセージを表示」が出ます。
- **ゴミ箱に入れると**、メッセージには「削除されたファイル」と出ます（チャンネルのドライブに書ける人には「ゴミ箱にあります · 戻す」）。
  **別の場所へ移すと**、移した先を見られない人（ゲストなど）には「表示できないファイル」と出ます。どちらも、その前に
  「このファイルは #… の 2 件のメッセージに付いています」と確かめます。
- 「投稿のファイル」のフォルダそのものは、名前の変更・移動・ゴミ箱への移動ができません（月のフォルダは動かせます）。
- 参加していない公開チャンネルのメッセージのファイルも、ファイルがそのチャンネルのドライブにある間は、メッセージから開けます
  （ドライブの一覧はメンバーだけです）。
- 容量はチャンネルのドライブに数えます。上限を超えていても **投稿は止めません**（止まるのはドライブへのアップロードだけです）。
- チャンネルの「ファイル」のタブ（メッセージの添付の時刻順）と「ドライブ」のタブ（フォルダ）の両方に出ます。

### メッセージを消すとき

自分が送ったメッセージを消すと、確認に「**ドライブの n 件のファイルもゴミ箱に移す**」が出ます（投稿のあとに誰も変えていない
ファイルだけ）。印を付けて消すとファイルもゴミ箱に入り、外すとチャンネルのドライブに残ります。ゴミ箱に移したものも 30 日以内なら
ドライブのゴミ箱から戻せます。投稿のあとに新しいバージョンが上がったファイルは、ドライブに残ります。

### チャンネルごとに切り替える

チャンネルのオーナーは、チャンネルの ⋯ →「**投稿したファイルをチャンネルのドライブに保存**」で「ワークスペースに従う / 保存する /
保存しない」を選べます（雑談やスクリーンショットばかりのチャンネルなど）。ワークスペース全体の既定は管理者が決めます（既定はオン、
[ドライブの管理](../admin/drive.md#channel-files)）。変えて効くのは、それからの投稿だけです。この機能より前の添付は、自動では
ドライブに入りません。

## 大きなファイルを会話に送る（100 MB を超えるもの） { #big-files }

添付の上限（既定 1 ファイル 100 MB、サーバの設定による）を超えるファイルを入力欄に入れると、断る代わりに
「**ドライブにアップロードしてリンクを投稿**」を選べます（スマートフォンは確認の画面。iPhone / iPad の動画なら「画質を下げて添付」も）。
ドライブのアップロードなので、大きなファイル（既定 5 GB まで）も分けて送り、切れても続きから送ります。

| 会話 | アップロード先 |
| --- | --- |
| 公開・非公開チャンネル（投稿のファイルがオン） | そのチャンネルのドライブの「投稿のファイル › 投稿した月」 |
| 公開・非公開チャンネル（オフ） | そのチャンネルのドライブのいちばん上 |
| 書き込めないチャンネル（投稿がオーナーだけなど）・DM・グループ DM | 自分のマイドライブ（**ほかの人はそのままでは開けません**。ドライブで共有するか、チャンネルのドライブに置いてください） |
| アーカイブしたチャンネル・ゲスト | 送れません（「大きすぎます」） |

アップロードの間も、ほかのメッセージは送れます。終わるとファイルのリンクが入力欄に入るので、確かめて送ってください。

## スマートフォンで使う { #phones }

iPhone・iPad・Android のアプリでは、ドライブを見る・ダウンロードするのと、写真やファイルの **アップロード**・新しいフォルダの作成が
できます（名前の変更・移動・ゴミ箱・共有リンクの作成は、デスクトップ版かブラウザ版で行ってください）。

- **開く**：ホームの上のタイルの「**ドライブ**」から。研究室ドライブ・マイドライブ・自分のチャンネルのドライブが並びます。
  公開・非公開チャンネルでは、会話の上のタブの「**ドライブ**」からそのチャンネルのドライブも開けます。
  タイルは「自分 → 表示 → ホームのタイル」で隠したり並べ替えたりできます。
- **フォルダをたどる**：フォルダを押すと中へ。上に出る場所（研究室ドライブ › 論文 › …）を押すと、そのフォルダへ戻ります。
  右上の ↑↓ で名前・更新日時・大きさの順（昇順・降順）に並べ替え、下へ引くと読み直します。たくさん入ったフォルダは、
  下までスクロールすると続きを読みます。ほかの人が足したファイルは、開いている間にそのまま一覧に出ます。
- **探す**：上の検索欄で、そのドライブの中をファイル名・フォルダ名と[ファイルの中身](#search-inside)で探します（「ドライブ」の最初の
  画面の検索欄はすべてのドライブから）。中身で見つかったものは、名前の下に見つかった語の前後が出ます。
- **見る**：写真・動画・PDF・Word / Excel / PowerPoint は、会話の添付と同じビューアで開きます（動画はダウンロードせずに再生します）。
  PDF はプレビューがまだ無くても（Nextcloud から移したファイルなど）、ファイルそのものを開きます。Word などでプレビューが
  まだ無いものは、開いたときにサーバが作り始め、「プレビューを作成中…」の後にページに替わります。プレビューを作れないファイルは
  そう出て、「ダウンロード」で取り出せます。そのほかのファイルは詳細が開きます。
- **アップロード**：書き込めるドライブのフォルダの「**＋**」から、写真・動画（複数選べます）、カメラ、ファイル（“ファイル”アプリ・
  Android のファイルの選択）、「新しいフォルダ」。同じ名前のファイルがあれば、デスクトップ版と同じく「上書きして新しいバージョンにする」「名前を変えて両方残す」
  「スキップ」を聞きます。進み具合は一覧の下の帯に出て、押すと一覧（取りやめ・再試行）が開きます。大きなファイルも少しずつ
  送るので、通信が切れても、アプリを閉じても、続きから送ります（iPhone・iPad はアプリが裏に回っても送り続け、Android は通知を
  出して送り続けます）。投稿がオーナーだけのチャンネルなど、書き込めないドライブには「＋」が出ません。
- **ほかのアプリから保存**：写真・ファイルアプリなどの共有ボタンから「Taylis」を選び、「**ドライブに保存**」にして保存先の
  フォルダを選ぶと、そのフォルダにアップロードします。共有の画面を閉じても送り続けます。
- **ダウンロード・共有**：行の ⋯ か詳細から、iPhone・iPad は「**ダウンロードして共有**」（ほかのアプリで開く・AirDrop など）か
  「**“ファイル”に保存**」、Android は「**共有**」か「**ダウンロードに保存**」。大きなファイルも、進み具合を見ながら
  少しずつ書き込みます（取りやめもできます）。フォルダは ZIP にまとめて同じように共有・保存できます。
- **会話のリンク**：メッセージのドライブのリンクは、下にカード（名前・場所・大きさ）が出ます。押すとビューアかフォルダが開きます。
  見る権限の無いファイルは「表示できないファイル」とだけ出ます（名前も出ません）。

## まだできないこと

次のものは順に対応します：スマートフォンでの名前の変更・移動・ゴミ箱と共有リンクの作成。
