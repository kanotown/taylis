# ドライブ

「ドライブ」は、研究室のファイルをフォルダに分けて置いておく場所です（Nextcloud や Google ドライブに近いものです）。
会話の添付と違って流れていかず、論文の PDF・発表資料・実験のデータなど、大きなファイルも置けます（既定は 1 ファイル 5 GB まで）。

今はデスクトップ版とブラウザ版で使えます。スマートフォンのアプリは、あとで閲覧とダウンロードから対応します。

## 3 つの場所

アイコン列の「ドライブ」（ハードディスクのアイコン）を開くと、左に場所が並びます。

| 場所 | 見られる人 |
| --- | --- |
| **研究室ドライブ** | ゲスト以外の全員 |
| **チャンネルのドライブ** | そのチャンネルのメンバー（公開・非公開チャンネル。DM にはありません） |
| **マイドライブ** | 自分だけ（管理者も中は見られません） |

「教員だけ」「M2 だけ」のように一部の人で使うファイルは、その人たちの非公開チャンネルのドライブに置きます。
まだドライブを開いていないチャンネルは「＋ チャンネルを選ぶ」から開けます。チャンネルの見出しの「ドライブ」のタブからも、
そのチャンネルのドライブを開けます。

場所の名前の下には、使っている容量が出ます（管理者が上限を決めていれば、その割合の棒も）。

## アップロードする

- ファイルやフォルダを、一覧にドラッグ＆ドロップします。フォルダの行の上に落とすと、そのフォルダの中に入ります。
- または「アップロード」→「ファイルをアップロード」「フォルダをアップロード」で選びます。フォルダは中のフォルダの形のまま入ります
  （空のフォルダも）。

右下にアップロードの欄が出て、ファイルごとの進み具合・速さ・残り時間が見られます。欄は別の画面に移っても残ります。

- **一時停止・再開・取りやめ** は、行のボタン（全部まとめてなら見出しのボタン）で。
- **ネットワークが切れても**、つながれば続きから送ります（「接続を待っています」と出ます）。最初からやり直すことはありません。
- **アプリを閉じても**、デスクトップ版は次に開いたときに続きから送ります。ブラウザ版はタブを閉じるとファイルを読み直せないため、
  「途中のアップロードが n 件あります」と出たら「ファイルを選び直す」で同じファイルを選んでください。続きから送ります
  （途中までの分はサーバに 24 時間残ります）。

### 同じ名前のファイルがあるとき

アップロードするフォルダに同じ名前のファイルがあると、どうするかを聞かれます。

- **上書きして版にする**：新しいものに置き換えます。前のものは古い版として残ります。
- **名前を変えて両方残す**：「名前 (1).pdf」のように名前を変えて置きます。
- **スキップ**：そのファイルは送りません。

「残りすべてに同じ操作」に印を付けると、その回のアップロードの残りにも同じ答えを使います。

## 見る・探す・ダウンロードする

- **リストとグリッド**：右上で切り替えます（この端末で覚えます）。リストは見出しを押すと名前・更新日時・大きさで並べ替えます。
- **開く**：フォルダはダブルクリックで中へ。写真・動画・PDF・Word / Excel / PowerPoint は、アプリの中のビューアで見られます
  （写真と動画は ← → で同じフォルダの前後へ）。そのほかのファイルはダウンロードになります。
- **探す**：上の検索欄で、その場所の中をファイル名とフォルダ名で探します。全部の場所から探すときは、いちばん上の検索欄で探して
  結果の「ドライブ」のタブを開きます（v1 はファイルの中身までは探しません）。
- **ダウンロード**：右クリック（または行の ⋯）→「ダウンロード」。デスクトップ版は「ダウンロード」フォルダに保存し、大きなファイルも
  少しずつ書き込みます。ブラウザ版はブラウザ自身のダウンロードになり、途中で切れてもブラウザの「再開」が使えます。
- **ZIP でダウンロード**：フォルダ、または複数選んだファイルとフォルダは、右クリック →「ZIP でダウンロード」で 1 つの ZIP に
  まとめて落とせます（詳細の欄の「ZIP でダウンロード」は、選んだもの、何も選んでいなければ開いているフォルダ全体）。
  フォルダの形・日本語の名前・空のフォルダもそのまま入り、Windows のエクスプローラーと macOS で展開できます。圧縮はしないので、
  大きさは元のファイルの合計とほぼ同じです。1 つの ZIP は 10,000 件・20 GB まで。それより大きいときはフォルダを分けて落としてください。
  ZIP は途中から再開できないので、とても大きなフォルダは分けるのがおすすめです。
- **詳細**：右上の ⓘ で、大きさ・種類・作った人・更新した人・版の数・場所が見られます。

## 整理する

- **新しいフォルダ**：上の「新しいフォルダ」。
- **名前を変更・移動・ゴミ箱へ**：右クリック（または ⋯）から。移動は行を別のフォルダやパンくずにドラッグしても、++ctrl+x++ →
  移動先で ++ctrl+v++（macOS は ++cmd++）でもできます。別の場所（研究室ドライブからチャンネルのドライブなど）へも移せます。
- **コピー**：右クリック →「コピー」で、コピー先のフォルダを選びます（書ける場所ならどこでも。同じフォルダにも）。または
  ++ctrl+c++ → コピー先で ++ctrl+v++（macOS は ++cmd++）。同じ名前があれば「名前 (1).pdf」のようになります。フォルダは中身ごと
  コピーされます（ゴミ箱のものは除く）。ファイルは今の版だけがコピーされ、コピーは新しいファイルとして版 1 から始まります。
  1 回にコピーできるのは 500 件・1 GB までです。コピーした分も、コピー先の容量に数えます。
- **キー**：++up++ ++down++ で選ぶ、++enter++ で開く、++space++ でプレビュー、++f2++ で名前を変更、++delete++ でゴミ箱へ、
  ++ctrl+a++（macOS は ++cmd+a++）ですべて選ぶ、++ctrl+c++ / ++ctrl+x++ → ++ctrl+v++ でコピー / 移動。

### 版の履歴

同じ名前で上書きする（アップロードで「上書きして版にする」を選ぶ）と、前のものは **古い版** として残ります。
ファイルを右クリック →「版の履歴」（または詳細の欄の「版」）で、版の一覧が見られます。

- どの版も ⬇ でダウンロードできます。
- **この版に戻す**：その版の写しが、新しい「今の版」になります。間の版も消えないので、戻したあとでまた別の版に戻せます。
  書ける人なら誰でもできます。
- **削除**（ごみ箱のアイコン）：古い版を完全に削除します。完全に削除できる人（研究室ドライブは管理者、チャンネルのドライブは
  チャンネルのオーナー、マイドライブは本人）だけです。今の版は削除できません。
- 古い版は、新しいものから **10 版まで**、新しい版に置き換えられてから **30 日間** 残り、それを過ぎると自動で消えます
  （サーバの設定で変えられます。一覧の上に今の決まりが出ます）。
- 古い版も、その場所の容量に数えます。プレビューは今の版だけです（古い版はダウンロードして開きます）。

### 容量

場所の名前の下に、使っている容量が出ます。管理者が上限を決めていれば、その割合の棒も出ます。上限を超えると、
アップロード・コピー・古い版に戻す・別の場所からの移動ができなくなります（「ドライブの容量の上限を超えます」）。
ゴミ箱のものを「完全に削除」するか、古い版を削除すると空きます。使っている容量には古い版とゴミ箱の分も入ります。

### ゴミ箱

右上のゴミ箱のアイコンで、その場所のゴミ箱が開きます。ゴミ箱のものは 30 日たつと完全に削除され、それまではいつでも
「元に戻す」で元の場所に戻せます（元のフォルダが無ければいちばん上に）。「完全に削除」は、研究室ドライブは管理者、
チャンネルのドライブはチャンネルのオーナー、マイドライブは本人だけができます。

## 学外の人に渡す（共有リンク） { #share }

ファイルやフォルダを、Taylis にアカウントの無い人（他大学の共同研究者など）に **リンク** で渡せます。リンクを知っている人は
誰でも、ログインせずにブラウザで開けます。

1. ファイルかフォルダを右クリック（または行の ⋯）→「**共有リンク**」。
2. 「新しいリンク」で決めて「**リンクを作る**」。
    - **期限**：1 日・7 日（既定）・30 日・90 日、または日付を指定。いちばん長い期限は管理者が決めています（既定 90 日）。
    - **パスワード**（任意。管理者が必須にしていることもあります）：パスワードは、リンクとは別の方法（電話・別のメッセージなど）で伝えてください。
    - **ダウンロードの回数の上限**（任意）：ファイルのダウンロードと「ZIP でダウンロード」を 1 回ずつ数えます。一覧を見る・
      プレビューは数えません。
    - **誰向けか**（任意）：自分と管理者の一覧に出るメモです（相手には見えません）。
3. 出てきた URL を「**コピー**」して、相手に送ります。

!!! warning "URL は作ったときにだけ表示されます"
    サーバにはリンクの URL の写しを残しません（漏れても使われないように）。あとからもう一度表示することはできないので、
    渡し直すときは新しいリンクを作ってください（古いほうは「取り消す」）。

- **フォルダのリンク** は、そのフォルダの中のすべて（**あとから入れたものも**）が見えます。外部に共有されているフォルダの中を開くと、
  一覧の上に「このフォルダは外部共有リンクで公開されています」と出ます。共有したくないファイルは、そのフォルダに置かないでください。
- **ファイルのリンク** は、そのファイルの今の版だけが見えます（古い版は見えません）。
- 相手のページ（`/s/…`）では、名前・大きさ・更新日時、ダウンロード、フォルダの「すべてを ZIP でダウンロード」、PDF・Word / Excel / PowerPoint の
  プレビュー、画像が見られます。**あなたの名前・研究室ドライブの中の場所・ほかのファイルは見えません。**
- 共有しているファイルとフォルダには、一覧の名前の横にリンクのしるしが付きます。

### リンクを管理する

「共有リンク」のダイアログの下に、その項目のリンクが並びます（自分が作ったもの。チャンネルのオーナーと管理者には全部）。
ドライブの左下の「**共有リンク**」には、自分が作ったすべてのリンクが並びます。

- **状態**：有効、期限切れ、回数の上限、停止中。
- **記録**：開いた・ダウンロードした・パスワードを間違えた日時（180 日残ります。IP アドレスは前の 2 つの区切りだけ）。
- **取り消す**：リンクはすぐに使えなくなります（元に戻せません）。

リンクは、次のあいだ **自動で止まります**（「停止中」。元に戻ればまた使えます）：

- 作った人がその場所を読めなくなった（チャンネルを抜けた・ゲストになった・アカウントが無効になった）
- そのチャンネルがアーカイブされた
- 項目をゴミ箱に入れた、または別の場所（ほかのチャンネルのドライブなど）へ移した
- 管理者がワークスペース全体で、またはその場所を管理する人がその場所で、外部リンクを止めた

リンクを作れるのは、その場所に書ける人だけです（ゲストは作れません）。ドライブのいちばん上（研究室ドライブ全体など）は共有できません。
チャンネルのオーナー（マイドライブは本人、研究室ドライブは管理者）は、場所の名前の ⋯ →「この場所で外部共有リンクを許す」で、
その場所のリンクを止められます。

## まだできないこと

次のものは順に対応します：会話にドライブのファイルを送る・会話の添付をドライブに保存する、スマートフォンのアプリ。
