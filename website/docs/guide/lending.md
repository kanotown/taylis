# 備品の貸し出し

研究室の PC・カメラ・本・ケーブルなどを、メンバーが **自分で借りて、自分で返す** ための台帳です。誰が何をいつまで
持っているかが全員に分かり、返す日が近づくと本人に、長く過ぎると備品係にも知らせが届きます。

管理者が有効にしたワークスペースだけで、アイコン列（スマートフォンはホームのタイル）に「**備品**」が出ます。ゲストには出ません。
設定のしかたは [備品の管理](../admin/lending.md) をご覧ください。

!!! tip "「予約」との違い"
    測定器を午後だけ・計算機を 3 時間のように **時間で使う枠** は [予約](reservations.md)、カメラや PC を数日 **持ち出す** のは
    備品の貸し出しです。

## 見る

「備品」には次のタブがあります。

| タブ | 中身 |
| --- | --- |
| 一覧 | すべての備品。名前・管理番号・置き場所で探し、分類と状態（貸出可・貸出中・修理中・延滞）で絞り込めます |
| 貸出中 | 誰が何をいつまで借りているか（返す日の順） |
| 自分 | 自分が借りているもの・最近返したもの、教員なら許可を求められた貸し出し |
| 延滞・管理 | 備品係だけ（[備品の管理](../admin/lending.md)） |

状態は色の点で分かります（緑＝貸出可、青＝貸出中、灰＝修理中、赤＝返す日を過ぎている）。備品を押すと、写真・置き場所・
付属品・教員の許可が要るか・最長の日数と、最近の貸し出しの履歴が出ます。

スマートフォンのアプリでも、見る・借りる・返す・延長・返却を待つ・教員の「許可していない」「確認した」ができます
（台帳の登録や編集は、デスクトップ版・ブラウザ版で備品係が行います）。

## 借りる

1. 備品を開いて「**借りる**」を押します。
2. **返す日** を選びます（既定はその備品の最長。最長より後は選べません）。
3. **目的** を書きます（例：学会発表の撮影）。
4. 🔑 **教員の許可が要る** 備品では、「**教員の許可を得た**」に印を付け、**許可した教員** を選びます（指導教員が先頭に出ます）。
   選んだ教員に知らせが届きます。
5. 「借りる」を押します。

同時に 2 人が借りようとしたときは、先に押した人が借ります。後の人には「〇〇 さんが先に借りました（10/30 まで）」と出ます。
教員が自分で借りるときは、許可の印は要りません。

## 返す・延長する

- **返す**：「返す」で、状態を「問題なし」か「問題あり」で選びます。「問題あり」のときはメモ（例：レンズキャップがありません）が要り、
  備品係に知らせが届きます。問題なしでもメモを残せます（例：充電器は棚の箱へ）。
- **延長**：「延長」で新しい返す日を選びます。延ばせるのは今日から数えてその備品の最長の日数まで、回数は既定で 2 回までです
  （「あと 1 回延長できます」と出ます）。返す日を過ぎてからでも延長できます。それより長く借りたいときは備品係に相談してください。
- 待っている人がいると、延長のときに「この備品を待っている人がいます（2 人）」と出ます。

## 返す日の知らせ

返す日はワークスペースの日付で数え、知らせは朝（既定 9:00）に届きます。

| いつ | 誰に |
| --- | --- |
| 返す日の前日と当日の朝 | 借りている人 |
| 返す日を過ぎてから毎朝 | 借りている人（返すか延長するまで） |
| 返す日を 3 日以上過ぎたら | 備品係にも（朝に 1 つのまとめ） |

知らせはアクティビティに残り、プッシュ通知も届きます（おやすみ時間や取り込み中の間はプッシュを出さず、アクティビティにだけ
残ります）。延長すると、新しい返す日でまた前日から知らせます。

## 返却を待つ

貸出中・修理中の備品で「**返却されたら知らせる**」を押すと、返却されたとき（修理が終わったとき）に 1 回知らせが届きます。
順番の予約ではないので、先に借りた人が借りられます。

## 教員の方へ：許可の確認

許可が要る備品は、借りる人が「教員の許可を得た」と **自分で申告** し、選ばれた教員に知らせが届く仕組みです。

- 知らせ（アクティビティ・プッシュ）を開くと、その貸し出しの備品・借りた人・返す日・目的が出ます。
- 許可していなければ「**許可していない**」を押します（一言も添えられます）。記録に残り、借りた人と備品係に知らせが届きます。
- 許可した覚えがあれば「**確認した**」を押せます（任意）。貸し出しの詳細に「教員が確認済み」と出ます。
- 判断は返却から 14 日まででき、それを過ぎると知らせは済みになります。押せるのは、その貸し出しで選ばれた教員だけです。

スマートフォンのアプリからも押せます。「自分」のタブの「許可を求められた貸し出し」にもまとまっています。

## QR のラベルとリンク

備品係が印刷した **QR のラベル** をスマートフォンのカメラで読むと、ブラウザ版のその備品のページが開きます（ログインの後）。
メッセージに貼った備品のリンク（`…/eq/…`）は、アプリの中では「📦 備品を開く」になり、押すと「備品」のその備品が開きます。
