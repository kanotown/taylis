# よくある質問 (FAQ)

## 使う人から

??? question "アプリを入れたのにログインできません。アカウントはどう作るのですか？"
    Taylis にはアプリからの新規登録はありません。所属する組織の Taylis サーバーの管理者に、アカウントを作って
    もらうか、招待リンクを送ってもらってください。サーバーの URL も管理者に確かめてください ([ログイン](guide/login.md))。

??? question "無料ですか？"
    アプリは無料で、広告もアプリ内課金もありません。サーバーは各組織が自分たちで用意して動かします
    (サーバーの費用はその組織の負担です)。

??? question "通知が来ません"
    設定の「通知」→「テスト通知を送る」で確かめてください。パソコンで操作している間はスマートフォンに通知しない、
    など、わざと送らない場面もあります ([通知の設定](guide/notifications.md))。

??? question "パスワードを忘れました"
    管理者に仮のパスワードを発行してもらってください。組織の Google アカウントでログインしている場合は、
    Google のパスワードの手続きに従ってください。

??? question "複数のチームの Taylis を使えますか？"
    はい。アプリの「ワークスペースを追加」から、いくつものサーバーにログインして切り替えられます。

??? question "`snake_case` のような `_` を含む言葉は斜体になりますか？"
    なりません。`_` で囲んだ斜体は、前後が空白か記号のときだけ効きます。前後が空白や記号でも斜体にしたくないときは、
    `\_` と書くと記号のまま表示されます ([メッセージの書き方](guide/formatting.md))。

??? question "管理者は私の DM を読めますか？"
    アプリでは、メンバーでない管理者は非公開チャンネルや DM を読めません。ただし、サーバーやデータベースを扱える
    人は、技術的にはすべてのメッセージを読めます ([プライバシー](privacy.md))。

??? question "アカウントを消したいです"
    設定 →「アカウント」→「アカウントを削除」で、いつでも削除できます。送ったメッセージは「退会したユーザー」の
    名前で残ります。消したいメッセージは、削除の前に自分で消すか、管理者に頼んでください。

## 管理者・サーバーの担当者から

??? question "何人まで使えますか？"
    数十人・数百の同時接続・数百万件のメッセージを目安に設計しています。それ以上の規模は想定していません。

??? question "Slack や Mattermost から移れますか？"
    はい。Slack のエクスポート (ZIP) と、Mattermost のチームを、会話ごと読み込めます
    ([Slack / Mattermost からの移行](self-hosting/import.md))。

??? question "公式のストアのアプリで、自分のサーバーのプッシュ通知を受け取れますか？"
    今のところ受け取れません (準備中)。プッシュはアプリの持ち主の鍵でしか送れないためです。アプリを開いている間は
    通知が出ます。詳しくは [プッシュ通知](self-hosting/push.md) をご覧ください。

??? question "AI を使わないといけませんか？"
    いいえ。AI は任意で、サーバーに API キーを置かなければ、AI の機能は画面に出てきません ([AI](admin/ai.md))。

??? question "バックアップはどうすればいいですか？"
    付属の `backup.sh` を cron で毎日動かし、ときどき `restore-rehearsal.sh` で戻せることを確かめてください
    ([バックアップと復元](self-hosting/backup.md))。

??? question "サポートはありますか？"
    ありません。Taylis は作者が自分たちで使うために開発し、そのままの形で公開しています。Issue やプルリクエストは
    受け付けていますが、対応・修正・今後の予定はお約束できません。

??? question "フォークして自分たちの名前で配ってもいいですか？"
    ソースコードは Apache License 2.0 なので自由に改変できます。ただし、改変したものを配るときは、「Taylis」とは別の
    名前とアイコンを使ってください ([ライセンス](license.md))。
