# プライバシーとデータの扱い

## データの持ち主はサーバーの運営者です

Taylis は **セルフホスト型** のチャットです。メッセージ・ファイル・アカウントの情報は、それぞれの組織が用意した
サーバーに保存されます。Taylis の作者のサーバーには送られません。

- どんな情報をどれだけの期間残すか、誰がサーバーを扱うか、バックアップをどこに置くかは、サーバーを運営する組織が
  決めます。使っているサーバーのデータの扱いは、その組織（管理者）に確かめてください。
- 公式のアプリのプライバシーポリシーは
  [Taylis のプライバシーポリシー](https://kano.ac/pages/apps/taylis-privacy-policy/) にあります。

## 保存されるもの

| もの | 内容 |
| --- | --- |
| アカウント | ユーザー名、表示名、メールアドレス（任意）、プロフィール画像、ステータス、パスワードのハッシュ |
| 会話 | メッセージ、添付ファイル、リアクション、キャンバス、予定、タスクなど |
| 端末 | 端末の名前・種類・アプリの版・プッシュ通知のトークン・最後に使った時刻 |
| 利用の記録 | 最終ログインと最終利用の日時、アプリを使った時間帯（1 時間単位、120 日で削除） |
| 記録 | 管理の操作の監査ログ、アプリのログ（トークン・パスワード・本文は出しません） |

## 管理者とサーバーの担当者に見えるもの { #admins }

- アプリでは、メンバーでない管理者は **非公開チャンネルや DM を読めません**。
- ただし、サーバー・データベース・バックアップにアクセスできる人は、技術的には **すべてのメッセージを読めます**。
  メッセージはデータベースの中で暗号化していません。
- 管理者は、報告されたメッセージの写しを確かめられます（報告した人が管理者に見せることを選んだものです）。
- 管理者は「アナリティクス」で、メンバーそれぞれの **最終ログインと最終利用の日時**、直近 30 日の **投稿の数**、
  ログイン中の端末の数と種類、ワークスペース全体の日ごとのメッセージ数と利用している人数を見られ、メンバーの一覧を
  CSV で書き出せます。**メッセージの内容は含みません**。管理者が参加していない非公開チャンネルと DM は、合計の数だけで、
  名前や相手は出ません。利用の記録（1 時間ごと）は 120 日で消えます（[アナリティクス](admin/analytics.md)）。

運営する組織は、このことを利用者に伝えたうえで、管理者とサーバーの担当者を決めてください。

## 外部のサービスに送られるもの

| サービス | 送られるもの | いつ |
| --- | --- | --- |
| APNs（Apple）/ FCM（Google） | 通知の題と本文（メッセージの抜粋）、送った人の名前と ID、端末のトークン。iPhone への通知には、送った人のアイコンを 24 時間だけ取れる URL も入ります | プッシュ通知を設定したサーバーで、通知を送るとき。サーバーの設定で本文を入れないようにもできます（そのときアイコンの URL も入れません） |
| Google | ログインの手続き | 組織の Google アカウントでログインするとき |
| Anthropic / OpenAI | 会話の一部と質問 | 管理者が AI を有効にし、メンション・要約・AI に聞くを使ったとき（画面に送り先を表示します） |
| リンク先のサイト | サーバーからの取得 | URL のプレビューを作るとき |

AI を有効にしていないサーバーでは、会話の内容が AI のサービスに送られることはありません。

## アカウントの削除

設定 →「アカウント」→「アカウントを削除」で、いつでもすぐに削除できます。

- **すぐに消えるもの**：プロフィール（名前・ユーザー名・メールアドレス・画像・ステータス）、ログイン情報、
  端末とプッシュ通知の登録。
- **残るもの**：共有の会話に投稿したメッセージとファイルは、ほかの参加者の記録として残り、投稿者は
  「退会したユーザー」と表示されます。消したいメッセージは、削除の前に自分で消すか、管理者に頼んでください。
- サーバーのバックアップには、削除の前の状態が保持期間（既定で 14 世代）のあいだ残ります。

ログインできないときは、サーバーの管理者に削除を頼んでください。各サーバーの `/account-deletion` のページにも
手順があります。
