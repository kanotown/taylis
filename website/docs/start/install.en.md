# Install the apps

You can use Taylis on a computer and on a phone with the same account; your read position is kept in step across
devices. You need your organisation's server URL and an account (or an invitation link) from its administrator.

| App | How to get it |
| --- | --- |
| Windows / macOS (desktop app) | Download the installer from [the GitHub releases](https://github.com/kanotown/taylis/releases/latest) |
| Browser | Nothing to install: open your server's URL |
| iPhone / iPad | Coming soon (App Store) |
| Android | Coming soon (Google Play) |

## Desktop app

1. Open [the latest release](https://github.com/kanotown/taylis/releases/latest) and download from "Assets":
    - **macOS**: `Taylis_<version>_universal.dmg` (Apple silicon and Intel)
    - **Windows**: `Taylis_<version>_x64-setup.exe` (an `.msi` is there too)
2. Install it. On macOS, drag Taylis to "Applications". On Windows, if SmartScreen says "Windows protected your PC",
   choose "More info" → "Run anyway".
3. Open Taylis, enter your server's URL and sign in.

The app checks for a new version at start-up and every six hours; choose **Update and restart** when it offers one
(or Settings → About this app → Check for updates). Closing the window keeps the app running in the background so notifications
still arrive; quit with ++cmd+q++ on macOS or from the tray icon on Windows.

## Browser

Open your server's URL (for example `https://chat.example.com/`) and sign in. It is the same app as the desktop
version and updates with the server. Notifications arrive only while the tab is open.

## Language

The apps are available in Japanese, English and Simplified Chinese: Settings → Display → Language (or follow the
device's language).

The rest of the user guide is in Japanese.
