# Taylis とは

Taylis（テイリス）は、研究室・ゼミ・小さなチームのためのチャットです。Slack と同じように、チャンネル・スレッド・DM で
話し、ファイルを共有し、過去の会話を検索できます。そのうえで、研究室でよく使う道具（ドキュメント、タスク、カレンダー、
日程調整、共有の機材の予約、在室状況など）を 1 つのアプリにまとめています。

## 使い始めるまで

1. **サーバーの URL とアカウントを用意します。** Taylis はそれぞれの組織が自分たちのサーバーで動かします。
   アプリから新しく登録することはできないので、管理者からサーバーの URL（例：`https://chat.example.ac.jp`）と、
   アカウントか招待リンクを受け取ってください。
2. **アプリを入れます。** パソコンはデスクトップ版かブラウザ版、スマートフォンはアプリです（[アプリを入れる](install.md)）。
3. **ログインします。** パスワード、組織の Google アカウント、招待リンクのどれかで入ります（[ログイン](../guide/login.md)）。
4. **通知を確かめます。** 設定の「通知」→「テスト通知を送る」で、端末に通知が届くかを確かめておくと安心です
   （[通知の設定](../guide/notifications.md)）。

## 画面の言葉

| 言葉 | 意味 |
| --- | --- |
| ワークスペース | 1 つの Taylis サーバー。研究室ごとに 1 つ、のように分かれます。アプリには複数を登録できます |
| チャンネル | テーマごとの会話の場所。公開チャンネル（`#`）と、招かれた人だけの非公開チャンネル（🔒）があります |
| DM | 1 対 1 や数人だけの会話 |
| スレッド | 1 つのメッセージへの返信のまとまり。チャンネルの流れを乱さずに話を続けられます |
| Times | 一人ひとりの作業ログのチャンネル（`#times-名前`） |

次は [使い方](../guide/index.md) で、画面の見かたとよく使う操作を確かめてください。できることの全体は
[機能の一覧](../features.md) にあります。
