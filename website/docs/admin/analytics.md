# アナリティクス

管理 →「アナリティクス」で、ワークスペースがどれくらい使われているかと、メンバーそれぞれが最後にログインした日時・
最後にアプリを使った日時を確かめられます。デスクトップ版とブラウザ版の管理画面にあります。

!!! info "見えるのは日時と数だけです"
    メッセージの内容は表示しません。参加していない非公開チャンネルと DM は、合計の数（会話の数と投稿の数）だけで、
    名前やメンバー、誰と誰の会話かは出ません。メンバーにもこのことを伝えておいてください
    （[プライバシーとデータの扱い](../privacy.md#admins)）。

## 期間と概要

上の「期間」で、過去 7 日・30 日・90 日を選びます。日の区切りは、見ている端末の時間帯です。

| カード | 意味 |
| --- | --- |
| メンバー | 有効なアカウントの数（管理者・ゲスト・無効の内訳）。ボットは数えません |
| 過去 24 時間 / 7 日 / 30 日に利用 | その間にアプリを使った人の数。30 日のカードには、一度もログインしていない人の数 |
| 期間中のメッセージ | 人が投稿したメッセージの数（スレッドの返信を含み、削除されたもの・ボットの投稿・参加や退出の表示は含みません） |
| 期間中に加わったメンバー | 期間中に作られたアカウントの数 |

## グラフ

- **1 日のメッセージ数** と **1 日の利用メンバー数** の棒グラフです。棒にポインターを合わせると、その日の数が出ます。
- 利用メンバー数は、この機能を入れた日から記録しています（それより前の日は 0 です）。

## よく使われているチャンネル・よく投稿している人

- 期間中の投稿が多いチャンネル（最大 10）と、投稿した人の数です。公開チャンネルと、あなたが参加している非公開
  チャンネルが名前付きで出ます。
- 参加していない非公開チャンネルと DM・グループ DM は、表の下に合計だけが出ます。
- よく投稿している人（最大 10）は、すべての会話の投稿の合計数です。

## メンバーの利用状況

| 列 | 意味 |
| --- | --- |
| 最終ログイン | 最後にログインした日時（パスワード・Google・招待からの登録）。ログインしたままの端末は数え直しません |
| 最終利用 | 最後にアプリを使った日時（数分単位）。アプリを開いて操作したとき、画面を前に出しているときに更新されます |
| 30 日の投稿 | 直近 30 日に投稿したメッセージの数 |
| 端末 | いまログインしている端末の数と種類 |

- 「3 日前」のように表示し、ポインターを合わせると日時が出ます。記録が無い人は「記録なし」です
  （この機能を入れる前にしばらく使っていなかった人など）。
- 列の見出しを押すと並べ替えます（もう一度押すと逆順）。
- 「N 日以上利用なし」で、しばらく使っていない有効なメンバーだけに絞れます。卒業した人や、招待したのにまだ使い始めて
  いない人を探すときに使います。
- 「CSV を書き出す」で、今の絞り込みと並びのまま全員分を CSV（UTF-8、Excel で開けます）に保存します。
  時刻は UTC です。

「ユーザー」タブの各行にも「最終ログイン 3 日前」（一度もログインしていなければ「未ログイン」）が出ます。

## サーバーの設定

既定のままで使えます。変えるときは `.env` に書きます。

| 環境変数 | 既定 | 意味 |
| --- | --- | --- |
| `ACTIVITY_WRITE_INTERVAL_SECONDS` | `300` | 1 人の最終利用を書く最短の間隔（秒） |
| `ACTIVITY_FLUSH_INTERVAL_SECONDS` | `60` | 利用の記録をまとめてデータベースに書く間隔（秒） |
| `ACTIVITY_RETENTION_DAYS` | `120` | 1 時間ごとの利用の記録を残す日数 |
