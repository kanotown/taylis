# 報告とモデレーション

メンバーからの報告、ブロック、アカウントの削除の扱いを説明します。どれも、数十人の招待制のワークスペースを
前提にした単純な仕組みです。

## メッセージの報告

メンバーは、メッセージの操作（⋯ や長押し）の「報告する」から、理由（迷惑・スパム / 嫌がらせ / 不適切な内容 / その他）と
補足を付けて報告できます。

1. 報告があると、有効な管理者全員に **モデレーションのボット** から DM が届きます（理由・投稿者・場所・補足・
   メッセージへのリンク）。不快な内容を通知に広げないよう、本文は DM に載せません。
2. 管理 →「報告」で、本文の写し（投稿者が後から編集・削除しても残ります）・理由・報告者を確かめます。
3. 必要な対応（メッセージの削除、ユーザーの無効化や削除）を、ふつうの管理の操作で行います。
4. 終わったら「対応済みにする」を押します。間違えたときは「未対応に戻す」で戻せます。

管理者がメンバーでない非公開の会話のメッセージも、報告の写しで内容を確かめられます（報告した人が管理者に見せることを
選んだものです）。

## ブロック

メンバーは、プロフィールの「ブロック」で相手をブロックできます。

- 相手のメッセージは自分の画面で折りたたまれます。
- 相手からの通知・プッシュは来なくなり、相手は自分に 1 対 1 の DM を送れなくなります。
- ブロックしたことは相手に知らされません。解除は、相手のプロフィールか、設定 →「アカウント」の一覧から行います。

ブロックは本人だけのもので、管理者の対応ではありません。困っている人がいたら、報告を使うよう案内してください。

## アカウントの削除

- **本人**：設定 →「アカウント」→「アカウントを削除」で、すぐに削除（匿名化）されます。管理者にはボットから
  「メンバーが自分でアカウントを削除しました」と DM が届きます（元の名前は書きません）。
- **管理者**：管理 →「ユーザー」の ⋯ →「削除（匿名化）…」。

どちらも、プロフィール（名前・ユーザー名・メールアドレス・画像・ステータス）・ログイン情報・端末とプッシュの登録を消し、
共有の会話に投稿したメッセージとファイルは「退会したユーザー」の名前で残します。

サーバーの `https://chat.example.com/account-deletion` に、削除の方法を説明する公開のページがあります
（アプリのストアの「アカウント削除の URL」に使えます）。

詳しくは [docs/MODERATION.md](https://github.com/kanotown/taylis/blob/main/docs/MODERATION.md) をご覧ください。
