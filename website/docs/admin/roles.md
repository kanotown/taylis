# ロールと権限

ワークスペースのロールは 4 つです。ロールを変えられるのは管理者だけです（管理 →「ユーザー」の行の ⋯）。

| ロール | 向いている人 | できること |
| --- | --- | --- |
| 管理者（`admin`） | 教員、サーバーの担当者 | すべての管理の操作 |
| 運営（`manager`） | 研究室を一緒に回す博士・修士の学生 | 日々の管理（下の表） |
| メンバー（`member`） | ふつうの利用者 | ふつうの利用 |
| ゲスト（`guest`） | 外部の共同研究者、卒業生 | 入れてもらったチャンネルの中だけ |

管理者は 2 人以上にしておくのがおすすめです（1 人だと、その人が休んだときに困ります）。

## 運営と管理者の違い

| 操作 | 運営 | 管理者 |
| --- | --- | --- |
| 招待リンク（メンバー・ゲスト） | ○ | ○ |
| ユーザーの一覧、メンバー・ゲストの表示名と肩書きの変更 | ○（メールアドレス・最終ログインは見えない） | ○ |
| 研究室の名簿 | ○ | ○ |
| チャンネルの管理（名前・投稿制限・アーカイブ・メンバーの除外・既定のチャンネル） | ○（公開チャンネルと、自分がメンバーの非公開チャンネル） | ○ |
| カスタム絵文字、投稿とキャンバスのテンプレート | ○ | ○ |
| 在室状況の状態、ほかの人の状態の設定 | ○ | ○ |
| 予約の枠 | ○ | ○ |
| 報告の確認 | ○（自分が読めない会話の写しは見えない） | ○ |
| ロールの変更、アカウントの作成・無効化・削除、パスワードと 2 要素認証のリセット | — | ○ |
| ワークスペースの設定、グループ、Webhook、在室状況の設定と連携、操作ボタン、AI、アナリティクス、ドキュメントの管理 | — | ○ |

- 運営も管理者も、**メンバーでない非公開チャンネル・DM・共有されていないドキュメントは読めません**。
- チャンネルの中では、運営はメンバーと同じです（チャンネルのオーナーでなければ、ほかの人のメッセージを消すことなどはできません）。
- 運営の操作も、管理者の操作と同じく監査ログに残ります。

チャンネルの中には、これとは別に **オーナー** と **メンバー** の役割があります（[チャンネル](channels.md)）。
