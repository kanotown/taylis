# ドキュメントの管理

[ドキュメント](../guide/docs.md) のページは、共有された人だけが読めます。**管理者でも、共有されていないページの本文は
読めません**（学生の個人のメモを守るためです）。

その代わり、管理 →「ドキュメント」で次ができます（デスクトップ版・ブラウザ版、管理者だけ）。

| 操作 | 内容 |
| --- | --- |
| 一覧 | すべてのページの題名・共有の相手と段階・最終更新を見られます |
| 引き取り | 自分にフルアクセスを付けます。卒業などでフルアクセスの人がいなくなったページや、誤って全員から外したページを戻すときに使います。必ず監査ログに残ります |
| 完全削除 | ゴミ箱のページをすぐに消します（ふつうは 30 日で自動で消えます） |

## Notion から移す

Notion の書き出し（「Markdown & CSV」）を、ページとデータベースとして取り込めます。サーバーのコマンドで行う作業です
（[Slack / Mattermost / Notion からの移行](../self-hosting/import.md)）。
