# 備品の管理

[備品の貸し出し](../guide/lending.md) は、研究室の PC・カメラ・本などを、メンバーが自分で借りて自分で返す台帳です。
既定ではオフです。管理の画面はデスクトップ版とブラウザ版にあります。

## 有効にする

設定 →「管理」→「**備品**」（管理者だけ）で次を決めます。有効にした後は、アイコン列の「備品」→「設定」のタブでも同じものを変えられます。

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| 備品の機能を使う | オンにすると、ゲスト以外の全員のアイコン列とホームのタイルに「備品」が出ます。オフにしても台帳と記録は残ります | オフ |
| 備品係 | 台帳の登録・編集と延滞の知らせを受け持つ人（20 人まで、ゲスト・ボットは不可）。管理者はいつも備品係と同じことができます | なし |
| 既定の最長の日数 | 分類や備品で決めていないときの、1 回の貸し出しの最長 | 14 日 |
| 本人が延長できる回数 | 借りた人が自分で延長できる回数 | 2 回 |
| 備品係に知らせる日数 | 返す日をこの日数過ぎた貸し出しを、備品係の朝のまとめに出す | 3 日 |
| 朝の知らせの時刻・タイムゾーン | 返す日の知らせを送る時刻と、返す日を数える日付のゾーン | 9:00・Asia/Tokyo |

備品係を選んでいない（または全員がいなくなった）ときは、備品係あての知らせは管理者に届きます。

## 台帳を作る（備品係）

アイコン列の「備品」→「**管理**」のタブで行います。

1. **分類** を作ります（例：PC・カメラ・本・ケーブル）。分類ごとに「教員の許可が要るか」と「最長の日数」の既定を決められます。
2. 「**備品を追加**」で、名前・分類・管理番号・置き場所・付属品とメモ・写真、（分類の既定と違えば）許可が要るか・最長の日数を入れます。
3. 数が多いときは [CSV](#csv) でまとめて入れます。

### 教員の許可

許可が要る備品は、借りる人が「教員の許可を得た」と自分で申告し、選んだ教員に知らせが届きます。教員は「許可していない」
（借りた人と備品係に知らせが届く）か「確認した」を押せます。代わりに押すことは、管理者や備品係にもできません。

教員の候補は、管理 →「名簿」で身分が「教員」の人（`@faculty` のグループ）です。名簿を使っていないワークスペースでは、
ゲスト以外の全員から選びます。

### 状態と延滞

- **状態の変更**：備品の「状態」で、貸出可・修理中・廃棄を切り替えます（理由を一言）。貸出中のものは変えられません。廃棄した備品は
  一覧から消え（「廃棄も表示」で出ます）、管理番号は空きます。履歴は残ります。
- **「問題あり」の返却**：備品係に知らせが届き、備品の詳細に「最後の返却：問題あり」と出ます。修理中にするかは備品係が決めます
  （自動では変わりません）。
- **延滞**のタブ：返す日を過ぎた貸し出しが、過ぎた日数の多い順に並びます。目的の確認・DM での連絡・**代わりに返却を記録**
  （棚に戻っていたのに押し忘れたとき。本人に知らせが届きます）・**返す日を変える**（延長の上限を超えて 365 日先まで）ができます。
- 無効にしたアカウントの人が借りたままの貸し出しも、備品係の朝のまとめに出ます。

## CSV の取り込み・書き出し { #csv }

「管理」→「**CSV**」で、台帳を表計算のファイルとやり取りできます。今のスプレッドシートの台帳から始めるときに使います。

- **書き出す**：Excel で開ける UTF-8 の CSV。列は「管理番号・名前・分類・置き場所・状態・許可が要る・最長の日数・付属品とメモ・借りている人・返す日」です。
- **取り込む…**：ファイルを選ぶと、まず **何も書かずに** 結果（新しく作る・変える・変わらない行、新しい分類、行ごとのエラー）を
  見せます。エラーが無ければ「取り込む」で反映します。
    - 備品は **管理番号** で突き合わせます（管理番号の無い行は名前で）。何度取り込んでも、同じ備品は増えません。
    - 「名前」の列は必須です。ファイルにある列だけを書き換えます（空のセルはその項目を空にします）。「借りている人」「返す日」は読みません。
      「状態」が「廃棄」の行は飛ばします。
    - 「許可が要る」は「要る」「要らない」（はい / いいえ、○ / × も）か空欄（分類の既定）、「最長の日数」は 1〜365 か空欄です。
    - 文字コードは UTF-8 と Shift_JIS（Excel の既定の保存）を読めます。1 MB・2,000 行までです。

## QR のラベル

「管理」→「**QR のラベル**」→「ラベルを作る…」で、選んだ備品の名前・管理番号・QR を、A4 のラベル用紙（24 面、70 × 37 mm）に
並べて印刷します。アプリから印刷できないときは「HTML で保存」して、ブラウザで倍率 100%・余白なしで印刷してください。

QR は備品のリンク（`https://<サーバ>/eq/<備品の ID>`）です。スマートフォンのカメラで読むと、ブラウザ版のその備品のページが開きます
（アプリは開きません）。リンクのページはログインするまで中身を見せません。
