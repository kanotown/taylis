# ワークスペースの設定

Taylis では **1 つのサーバー (デプロイ) が 1 つのワークスペース** です。チームを分けたいときは、サーバーをもう 1 つ
立てて、アプリの「ワークスペースを追加」から両方を登録します。

## 名前

ワークスペースの名前は、サーバーの `infra/.env` の `WORKSPACE_NAME` で決めます (空なら「Taylis」)。アプリの
ワークスペースの切り替えや検索欄に出ます。変えたらアプリを再起動してください (`docker compose ... up -d app`)。

## 管理 →「設定」

### アイコン

ワークスペースのアイコンの画像 (PNG・JPEG・WebP) を選ぶと、すぐに反映されます。中央の正方形を切り抜いて 256 px に
作り直します。ワークスペースの切り替えやログイン画面に出ます。「削除」で頭文字のアイコンに戻ります。

アイコンはログインの前の画面にも出すので、認証なしで取得できます (秘密の画像は使わないでください)。

### 既定のチャンネル { #default-channels }

新しく入った人 (ゲストとボットを除く) が自動で参加する公開チャンネルの一覧です (20 個まで)。

- 対象は、管理者が作ったアカウント・サーバーのコマンドで作ったアカウント・招待で参加した人・Google での自動作成の人です。
  Slack / Mattermost の移行で作った人は入りません。
- まだ何も設定していなければ、「「全体連絡」と「談話スペース」を既定にする」のボタンで始められます (無ければ作ります)。
- **今いる人も全員入れる**: いまの有効なメンバーを、入っていない既定のチャンネルに入れます (人数を確かめてから実行)。
  移行の後などに使います。
- アーカイブしたチャンネルや非公開にしたチャンネルは、一覧から自動で外れます。

### 参加・退出の表示

オンにすると、公開・非公開チャンネルに「〇〇 が参加しました」「〇〇 が △△ を追加しました」の 1 行が出ます (既定オン)。
この行は未読・バッジ・通知・検索には入りません。オフにしても、すでに出た行は残ります。

### 参加前にチャンネルの中を見られる

オン (既定) なら、公開チャンネルに参加する前に中のメッセージを読めます。オフにすると、未参加の公開チャンネルは
名前・説明・人数だけが見え、中身は参加してから読めます (管理者も同じです)。

## サーバーの設定 (`infra/.env`)

管理画面ではなく、サーバーの環境変数で決めるものもあります。よく使うものだけ挙げます。

| 変数 | 内容 | 既定 |
| --- | --- | --- |
| `WORKSPACE_NAME` | ワークスペースの名前 | Taylis |
| `PASSWORD_MIN_LENGTH` | パスワードの最小の文字数 | 8 |
| `ATTACHMENT_MAX_BYTES` | 添付ファイルの上限 (Caddyfile の上限とそろえる) | 104857600 (100 MB) |
| `SSO_GOOGLE_*` | Google でのログイン | 無効 |
| `PUSH_APNS_*` / `PUSH_FCM_*` | プッシュ通知 | 無効 |
| `AI_*` | AI | 無効 |

すべての変数は [infra/.env.example](https://github.com/kanotown/taylis/blob/main/infra/.env.example) にあります。
