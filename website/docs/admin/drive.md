# ドライブの管理

[ドライブ](../guide/drive.md) は、研究室のファイルを置く場所です。管理者は、ドライブに **どれだけ** 置かれているかを見て、
場所ごとに容量の上限を決められます。**中身（ファイルの名前や内容）は、この画面には出ません。** マイドライブと、
自分がメンバーでない非公開チャンネルのドライブの中は、管理者でも開けません。

## 管理 →「ドライブ」

デスクトップ版・ブラウザ版の設定 →「管理」→「ドライブ」（管理者だけ）。

| 欄 | 内容 |
| --- | --- |
| ドライブ全体 | 合計の使用量と、その内訳（今の版・古い版・ゴミ箱）、ファイルとフォルダの件数。全体の上限があればその割合の棒 |
| 会話の添付 | メッセージ・キャンバス・ページに付けたファイルの合計（参考。容量の上限には数えません） |
| 場所ごと | 研究室ドライブ・チャンネルのドライブ・各人のマイドライブの使用量（内訳つき）、件数、上限、最後に変わった時刻。アーカイブしたチャンネル・無効にした人には印が付きます |
| 人ごと | その人が置いたファイルの版の合計（研究室ドライブやチャンネルのドライブに置いた分も含みます） |

使用量には、今の版のほかに **古い版**（上書きで残った前のもの）と **ゴミ箱** の分も入ります。完全に削除されるまで、
ディスクを使っているためです。古い版は新しいものから 10 版まで、置き換えられてから 30 日、ゴミ箱は 30 日で自動で消えます。

## 容量の上限

場所ごとの「上限」の欄に GB で入れて「保存」します（小数も可。空欄にすると上限なし）。変更は監査ログに
`drive.quota_changed` として残り、その場所を開いている人の画面にもすぐ反映されます。

- 上限を超えると、**追加** だけが止まります：アップロード、コピー、古い版を戻す、別の場所からの移動。
  名前の変更・同じ場所の中の移動・ゴミ箱へ・完全に削除はいつでもできます（減らす操作は止めません）。
- 今の使用量より小さい上限にしても、中身は消えません（減らすまで追加できなくなるだけです）。
- チャットの添付（会話のファイル）は上限に数えません（1 ファイル 100 MB の上限だけです）。

### 全体の上限とマイドライブの既定の上限

サーバの `infra/.env` で決めます（変えたら app を再起動）。

| 変数 | 意味 | 既定 |
| --- | --- | --- |
| `DRIVE_TOTAL_QUOTA_BYTES` | ドライブ全体（すべての場所の今の版・古い版・ゴミ箱の合計）の上限（バイト） | なし |
| `DRIVE_USER_DEFAULT_QUOTA_BYTES` | 自分の上限を決めていないマイドライブの上限（バイト）。研究室ドライブに置いてほしいときに | なし |
| `DRIVE_VERSIONS_MAX` / `DRIVE_VERSIONS_DAYS` | 古い版を残す数と日数 | 10 / 30 |
| `DRIVE_COPY_MAX_ITEMS` / `DRIVE_COPY_MAX_BYTES` | 1 回のコピーの上限（件数とバイト） | 500 / 1 GB |
| `DRIVE_ZIP_MAX_ENTRIES` / `DRIVE_ZIP_MAX_BYTES` | 1 つの ZIP の上限（件数とバイト） | 10,000 / 20 GB |

!!! warning "ディスクの空きはアプリからは見えません"
    アプリが数えるのはドライブに置かれた量だけで、サーバのディスクの空きは分かりません。ディスクがいっぱいになる前に
    止められるよう、**全体の上限はディスクの空きより十分小さく** 決めてください（例：空き 217 GB のサーバで 150 GB。
    バックアップの一時の領域・大きなファイルのアップロードの完了の間の 2 倍・PostgreSQL の伸びを残すため）。
    空きはサーバで `df -h` を確かめます（[バックアップと復元](../self-hosting/backup.md)）。

## 使用量の数え直し

場所ごとの使用量と件数は、ファイルを足したり消したりするたびに数えています。万一ずれたときは、サーバのコマンドで
確かめて直せます（サーバの `infra` のフォルダで）。

```sh
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec app python -m app.cli drive-usage --verify
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec app python -m app.cli drive-usage --rebuild
```

`--verify` はずれている場所を表示し（ずれがあれば終了コード 1）、`--rebuild` はずれている場所の数を版と項目から数え直します。
